# Tic Tac Toe Frontend (Remotion)

This is an interactive Remotion (React) composition implementing a Tic Tac Toe UI with the "Ocean Professional" theme.

Key features:
- Centered 3x3 grid with rounded corners, subtle shadows, and smooth transitions.
- Status pill shows Turn, Winner, or Draw.
- Reset / New Game buttons.
- Accessible labels, ARIA live region, and keyboard focusable buttons.
- Responsive layout, mobile friendly. Uses gradient background (from-blue-500/10 to-gray-50), white surface, and text color #111827.

How to run:
- npm i
- npm run dev
- Select the "TicTacToe" composition from the left panel in Remotion Studio.

Theme:
- Primary: #2563EB (blue)
- Secondary/Accent: #F59E0B (amber)
- Error: #EF4444
- Background: #f9fafb
- Surface: #ffffff
- Text: #111827
